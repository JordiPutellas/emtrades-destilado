### CPS: framework, no setup único

- El gráfico enumera: `1 Liquidity Base → 2 Point of Release → 3 Skinny Leg → 4 Price Pause / Shelf Bottom → 5 Continuation Leg → 6 Consolidation Apex → 7 Retest H/L → 8 Apex Base (break) Retest → 9 Shelf Top/Bottom Retest → 10 Gap slip → 11 Clean Breaking Point → 12 PoR → 13 Liquidity Base Bottom`. Más tarde prescribe escoger **un solo feature**, fijar parámetros y construir su sample set; ese feature se convierte en un trade del arsenal. ### Trading on the principles

- `First of all, we're trading on the principles`: price seeks/finds liquidity; liquidity actúa como friction; un run fino que llega a una base gruesa coloca al trader ante una respuesta potencialmente manejable hacia el lado más débil. [VID-PS: PriceSwing_01 @ 00:00:19–00:01:04]
- `Extensions get filled`: la formulación temprana espera que el leg se seque y vuelva al extension point. Es una expectativa causal, no una tasa ni un timing. [VID-PS: PriceSwing_01 @ 00:01:04–00:01:22]
- **Estatus:** `PRECURSOR REFINADO EN M2020`: M2020 conserva liquidity/weakness/exhaustion, pero separa fill, core response y reversal y exige seguimiento dinámico.

### Core frente a residual

- El caso preferido combina skinny-leg extension débil con `massive liquidity inside of the base, the core base`, buscando una `more manageable response`. [VID-PS: PriceSwing_01 @ 00:01:34–00:02:06]
- Un nivel residual en mitad del run tiende a ofrecer respuestas pequeñas; una base semanal puede ofrecer una respuesta mayor. Un nivel LTF puede fallar si el precio acaba de recoger liquidity HTF contraria. [VID-PS: PriceSwing_01 @ 00:02:22–00:02:50] [VID-PS: PriceSwing_01 @ 00:03:37–00:04:07]

## 4. Reglas y expectativas literales

- El liquidity-base retest o swing retest de una base/pickup es **un feature** del run, nunca definitivo: precio puede reaccionar poco o atravesarlo. [VID-PS: PriceSwing_01 @ 00:03:00–00:04:07]
- La selección debe aprender cómo llega el precio y cómo debe responder para conservar probabilidad favorable; los parámetros nacen de repetir el ejercicio, no del diagrama CPS. [VID-PS: PriceSwing_01 @ 00:02:50–00:03:37]
- La fractalidad ya está operativa: una liquidity base amplia contiene price pauses, shelves, apex, shelf flip, gap slips y otro core base en escala menor. [VID-PS: PriceSwing_01 @ 00:04:44–00:05:13]

## 5. Comparación con M2020

- **Conservado:** framework→feature→sample set; core/residual; incompatibilidad entre nivel LTF y contexto HTF; fractalidad.
