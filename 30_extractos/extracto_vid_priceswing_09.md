## 2. Secuencia CPS completa observada

1. **Inventory bajista activo:** cada extension hace fill/drawback al último sell inventory y desde allí crea un nuevo low. [VID-PS: PriceSwing_09 @ 00:00:12–00:01:18]
2. **Agotamiento relativo:** tras recorrido prolongado y pickup de opposing liquidity, el último sell shelf responde pero ya no logra nuevo low. [VID-PS: PriceSwing_09 @ 00:01:18–00:02:24]
3. **Shift:** bids sostienen, se deal-off el sell inventory y el low-liquidity state permite el run alcista. El cambio real no es una vela aislada sino el fracaso funcional del inventory seguido de price atravesándolo. [VID-PS: PriceSwing_09 @ 00:02:24–00:02:47]
4. **Run alcista:** price pause/accumulation → inefficient extension → drawback/fill → nuevo base/inventory → continuación. [VID-PS: PriceSwing_09 @ 00:02:47–00:04:41]
5. **Deterioro alcista:** un leg deja fill incompleto, aumenta la ineficiencia; después el último buy inventory/shelf falla en crear high y price lo atraviesa. [VID-PS: PriceSwing_09 @ 00:04:01–00:05:56]
6. **Wash/shift bajista:** highs recogidos y top/middle/bottom del shelf repetidamente picked dejan niveles drenados; al romper el shelf, sellers toman control y price atraviesa residual liquidity hasta el core/origen. [VID-PS: PriceSwing_09 @ 00:06:00–00:07:08]
